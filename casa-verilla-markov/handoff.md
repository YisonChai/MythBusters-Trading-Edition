## 解压及目录映射

将附件放在同一空工作目录，验证外部 `SHA256SUMS.txt` 后逐个解压：

```bash
sha256sum -c SHA256SUMS.txt
for f in 01-core.tar.xz 02-alternatives-ywf.tar.xz 03-alternatives-aliplayer.tar.xz; do
  tar -xJf "$f"
done
python3 materials/prepare_for_edit.py
```

三个tar.xz是独立归档，不需要cat重组。后三方数据核查档案会还原到第三版 `data/raw/alternatives/`。它们没有进入模型，仍保留是为了覆盖核查可审计，不要当作已用于全年训练。

每版结构：

```text
版本目录/
  src/                     原始代码，不改模型/参数/结论
  data/raw/                原始报价、规则、最终标签、费用快照、参考数据、探针
  data/results/            原始预测、信号、逐笔、资金、校准和审计CSV/JSON
  data/logs/               原始请求、复用指纹、冻结时间、运行与检查日志
  raw -> data/raw          保持旧代码路径兼容
  results -> data/results
  logs -> data/logs
  docs/                    原始来源说明与审计基线
  REPORT.html              第二、三版现有报告副本；首版需要生成
  *.md                     原始协议、README、中文结果说明
  ORIGINAL_FILES_SHA256.csv 原交付时的历史清单，不是本次精简包清单
```

`SOURCE_MANIFEST.csv`逐文件记录原版相对路径、交接路径、大小和SHA256。`EXCLUSIONS.json`列出每个未带文件及原因。源文件的字节没有重写。完整数据文件全部保留，包括第三版未入模HF核查Parquet。

为了压缩附件体积，完全相同的文件在tar中用硬链接去重。修改代码、MD、HTML前先运行 `prepare_for_edit.py`，它仅打断非data文件的硬链接，不改文件内容，不计算收益。原始data保持不可变；Git会按blob自身去重，不要求仓库保留硬链接。不要改原始data文件来“修好”结果。

没有带嵌套ZIP、Python缓存、可重建的dashboard_data.json和从HTML提取的JS副本。预测、逐笔、资金CSV、审计、所有原始请求与协议均保留。年版dashboard_data.json约109MB，超过GitHub普通单文件限制且可重建，不能顺手重新提交它。已有HTML内部已经带完整图表与逐笔数据，不需要为添加解释而重算模型。

原始清单可能列有本次明确排除的中间文件，请以SOURCE_MANIFEST与EXCLUSIONS解释差异，不要把有意精简误报为数据遗失。现有源码路径通过根目录三个兼容符号链接保持可用；若改成显式data路径，必须只做路径适配，不改研究方法，保留说明。

## 必须加到每个REPORT.html的通俗解释

请增加一个清晰、可折叠或可导航到的“用买票理解策略”章节，沿用原报告样式，明确全部例子数字是假设，不是回测交易。可以直接用以下内容：

### 1. 买一张结果票

Polymarket的一张“Up结果票”现在卖0.90美元。买100份花90美元。如果到期按该市场真实规则判为Up，100份共兑回100美元，毛赚10美元；判为Down则兑回0，亏90美元。这里暂不含手续费。赢不赢取决于合约写明的参考源和起止比较，不是看这张票本身涨没涨。

### 2. 第一关：市场有没有卖便宜

假设模型估计到期Up概率p=0.96，市场报价q=0.90，差值是0.06，超过0.05，所以通过第一关。这不代表模型一定正确；如果真实概率被高估，期望优势就会消失。不能把模型说出的96%当成已经证实的胜率。

### 3. 第二关：下一次检查还像不像现在

为了方便理解，假设把“票价高、近期波动小”叫一种状态。历史上100次类似状态中，90次在下一个采样时刻仍属同一类，可以说这种教学状态的一步持续率约90%，超过87%，通过第二关。

它不是说价格一分钱不动，更不是到期90%会赢。例如把0.85至0.95作为教学价格桶，0.90变成0.88仍在同桶，最后也完全可能输钱。87%这道过滤能不能改善收益必须回测验证，数值没有神奇保证。

**必须紧接着写清真实算法区别：**
“票价高、波动小”和0.85至0.95的宽桶只是教学假设，原帖没有披露真实状态定义。我们的实际研究使用另行声明的模型，不是Bonereaper内部算法。第二、三版到期概率大模型是6600个理论状态的稀疏/分层吸收马尔可夫链，不是CRF。共同的持续率过滤单独使用20档价格的一步转移矩阵，先取 j*=argmax_j P[i,j]，再看 P[j*,j*]，并不直接等同教学例子的P[i,i]，也不是完整6600状态的对角线。原版一分钟、后两版五分钟采样，持续率不能直接跨采样频率比较。”

注意：实际20档每桶0.05，教学宽桶0.85至0.95不是实际分桶；0.90到0.88的例子只解释教学宽桶，不得声称两者在真实0.05分桶中一定同桶。

### 4. 到底在赌什么

两个条件都通过才产生研究信号。关键不是“状态稳就稳赢”，而是模型的到期概率估计能否比市场更准，并覆盖费用、价差、滑点和延迟。原帖状态持续率不是交易胜率，高胜率也不等于高利润。没有历史盘口和深度，三版都只能称报价代理模拟，不能把显示价说成保证能成交100份。
