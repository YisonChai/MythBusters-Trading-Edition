# 月度马尔可夫回测结果

## 结论

**扩大到6600个理论状态后，仍没有得到超过市场价格的到期概率预测能力；部分低频策略在历史报价代理中盈利，但加入5分钟延迟与2美分压力后转亏，不能据此证明原帖机器人有稳定可执行优势。**

本次确实在 Bot 电脑运行了训练、验证、独立历史测试和资金账本，没有交易、连接钱包或使用用户电脑。它不是 Bonereaper 真实算法的复刻，也不是实盘。

## 2. 前次方法审计与本次修正

详细见《前次方法审计.md》。核心约束如下：

1. 历史价格是300秒聚合桶，不是逐分钟成交。桶开始时间不等于可见时间，本次一律推迟300秒才允许使用。
2. 不前向填充缺桶。动量/波动率需四个真实连续Up点，同时要求当前Down报价。resolution_seconds=0、0/1边界终局点不进入模型特征。
3. 历史显示价可能反映标价延续，不能证明存在同价买单/卖单或实际成交量。没有历史盘口，所有利润都是**历史价格代理模拟，非可执行收益**。
4. 标签可用时间取max(官方closedTime,市场到期+1小时)，训练和验证/测试间另留一天缓冲。
5. feeSchedule是抓取时元信息快照，不是不可变的历史费率档案。采用该快照建模，并报告零费、双费压力，不把它冒称准确复原历史手续费。
6. 本次一步为5分钟，87%持续率不能与前次1分钟版本直接比较。
7. 旧5分钟合约的1分钟历史探测返回200但0个价格点，见raw/five_minute_coverage*。这不证明所有接口都绝不可能有历史，但不足以支持本次30天分钟级5分钟产品实验，所以没有拿一小时产品冒充它。

## 3. 模型：预测到期结果，不预测下一步就当到期

- 每个状态先估计稀疏转移，末步吸收到真实Up=1/Down=0，再按剩余时间反向递推到期Up概率。
- 中/大状态按同价位/时间的小模型概率收缩；样本不足或未见状态硬回退。不是CRF，也不是拿一步价格持续率当终局胜率。
- 动量是当前Up价减前5分钟Up价；波动率是最近3个价差的标准差。每个特征只使用当时可用报价。
- 小模型是前次“价位×剩余时间”架构在统一300秒口径下的重建，不是旧逐分钟配置的逐字复跑，旧月度分钟数据并不齐全。小模型价格20档×剩余时间11档。中模型加入3档动量、2档波动率。大模型加入5档动量、3档波动率和2种资产。
- 中/大仅比较预先规定的alpha/min_count两组10/5、50/15，用训练内验证Brier选择，最后用全部30天重拟合。选出中模型50/15、大模型10/5；小模型固定10/5。
- 持续率过滤另用共同的20档价格一步矩阵，j*=argmax(P[i])，持续率=P[j*,j*]。如果把包含时钟的全状态对角线当持续率，因时钟必变会接近零，所以不能那样定义。

|模型|理论非终局状态|实际访问|每状态中位样本|测试已见状态覆盖率|测试硬回退率|
|---|---:|---:|---:|---:|---:|
|小|220|202|64.5|100.00%|0.00%|
|中|1320|894|8|99.34%|20.22%|
|大|6600|2974|3|95.45%|33.03%|

大模型状态更多，但中位数只有3个训练样本，约三分之一测试观测触发回退。扩大状态并不等于增加有效信息。分位数、状态计数、校准分桶与完整候选验证分数均在CSV和HTML。

## 5. 固定资金规则与真实计算结果

初始模拟本金10000美元，每市场100份、最多一笔、持有至真实结算，不加杠杆，BTC/ETH并发共享现金，不足即跳过。候选信号按时间排序，同秒先批量结算，再按市场ID下单。所有模拟账本逐笔校验。240个组合是独立研究账户，不把它们的资金或收益相加；全量交易CSV中同市场可出现在不同组合，但每组合每市场最多一笔。

三种固定策略：
- 原帖门槛研究版：预测方向概率减该方向报价至少0.05，且状态持续率至少0.87。
- 去持续率：只要求差值至少0.05。
- 配图门槛研究版：差值至少0.03、持续率至少0.87、方向报价0.83至0.97。

下表均为元数据手续费情景，单位美元，仅历史报价代理：

|模型|5%+87%：笔数 / 净盈亏|5%不设持续率：笔数 / 净盈亏|3%+87%+价带：笔数 / 净盈亏|
|---|---:|---:|---:|
|小|18 / +60.17|149 / -485.68|91 / -9.77|
|中|19 / -30.93|154 / -485.54|88 / +166.78|
|大|34 / +79.50|196 / -511.86|109 / +286.32|

固定简单基线是在开盘后第5分钟买高报价方向，330笔净亏784.13美元。市场价模型与自身比较没有概率差，所以其三个差值策略是0笔，页面明确显示无交易，不造曲线。

大模型分解：
- 5%+87%：32胜2负，胜率94.12%，毛利98.55，手续费19.05，净利79.50，期末10079.50，已实现口径最大回撤92.04。
- 去持续率：96胜100负，毛亏249.50，手续费262.36，净亏511.86，期末9488.14，最大回撤1133.21。
- 3%+87%+价带：104胜5负，胜率95.41%，毛利340.40，手续费54.08，净利286.32，期末10286.32，最大回撤126.06。

高胜率不是独立优势证据：买的是高概率高价合约，盈利必须覆盖高入价、尾部亏损与费用。此处没有经过多窗口稳定性或显著性验证，不年化。

## 6. 成本压力与失败条件

|大模型策略|零费|元数据费|每份再加1美分|延迟5分钟、较差价再加2美分|双倍费|
|---|---:|---:|---:|---:|---:|
|5%+87%|+98.55 (34笔)|+79.50 (34)|+47.49 (34)|-126.38 (20)|+60.45 (34)|
|5%不设持续率|-249.50 (196)|-511.86 (196)|-707.65 (196)|-1630.27 (172)|-774.22 (196)|
|3%+87%+价带|+340.40 (109)|+286.32 (109)|+183.85 (109)|-149.73 (67)|+232.24 (109)|

- 延迟是下一个真实300秒观测，不是伪造1分钟报价。使用原价与下一点的较差者再加0.02，缺下一点、到期或入场总成本不合要求则跳过，所以各情景不一定同一批交易，不能叫严格可成交下界。
- +1/+2美分是明确假设，不是观测盘口。没有bid/ask和深度，不能声称能买到100份，更不能把这里当真实执行收益。
- 元信息费率为0.07、指数1，费用按100×0.07×p×(1-p)及官方小数位规则计算，不含任何并不存在的交易返佣假设。更早历史费率修订、maker/taker身份仍未完全验证。
- 小样本、报价聚合、结算产品差异、状态非平稳、连续决策相关、历史费率不确定、价格可成交性不明都是失败条件。
- 当下这个7日样本支持“过滤能减少交易且本次表现较好”，不支持“87%是通用最优门槛”或“作者公开收益已被验证”。

## 7. 权益、回撤与审计

结算赢家来自真实历史结果，但资金释放时间按max(官方closedTime,到期)作模拟，并未证明同一时刻能够赎回或到账；训练标签可用时间另推迟到至少到期后1小时。

资金曲线不是盯市权益。未结算仓位按含费用的入场全成本保留，只有结算后把真实净盈亏计入权益；现金和占用本金另列。这会看不到持仓期间的浮亏，因此不能用图中最大回撤代替真实盘中风险。

曲线从10000开始，延续至最后一笔真实结算，测试信号窗口结束后仍可能有结算尾段。同秒结算批处理避免虚构事件排序导致的回撤。利润、手续费、份数、结算回款、现金与权益逐项对账。

检查结果：
- 8项单元测试通过，其中专门测试同秒先结算后入场、结算批处理、现金不足跳过、费用与无交易组合。
- 262项实际数据审计通过，覆盖全部240个模型×产品×策略×成本组合的账本、权益及边界条件。
- 重跑后14份结果CSV的SHA256全部相同。
- Node静态DOM桩测试遍历240个HTML组合、无交易提示、曲线数值、搜索、排序、分页、盈亏筛选与CSV导出通过；导出196笔样本与Python账本对账通过。
- HTML脚本语法检查通过，无CDN、外部脚本、自动联网或密钥输入。**未做真实浏览器视觉/交互验收**，没有把Node桩测试说成浏览器测试。
